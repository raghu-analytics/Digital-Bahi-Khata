# Digital Bahi-Khata v1.0

A simple Hindi digital ledger (android) app designed for small shopkeepers.

### Features

* Customer management
* Udhaar (credit) and Jama (payment) tracking and date-wise entry
* Customer-wise transaction history
* Monthly Reports
* PDF export of monthly reports, Bill vouchers and customer's monthly transactions
* Data backup, restore ( .db SQLite database file) and export as a single .xlsx file
* Built with **Kotlin and Jetpack Compose**
* Local **SQLite/Room database** for offline data storage

The app is designed to be simple, fast, offline and easy to use for everyday shop management.

**This is an android app completly created using AI (Google's AI Studio) as a my learning AI Tools.**
